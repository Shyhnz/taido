# Security policy

## Reporting a vulnerability

Please report security problems privately. Do not open a public issue.

Use GitHub's private reporting: open the **Security** tab of this repository and click **Report a vulnerability**. Include what you found, how to reproduce it and which version you tested.

You will get an answer as soon as possible. Please give us time to fix the problem before you disclose it.

## Scope

This covers the desktop app, the sync server and the phone app in this repository. Taido keeps its data locally. If you run the sync server yourself, keeping it updated and behind HTTPS is your responsibility (see `docs/SELF-HOSTING.md`).
